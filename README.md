# Школьные опросы

Веб-приложение для проведения опросов среди учащихся школы. Без внешних зависимостей:
сервер на встроенном модуле Node.js `http`, база данных — встроенный `node:sqlite`,
экспорт в Excel/PDF — собственные генераторы. Один процесс, один файл БД — легко
развернуть и обслуживать.

## Возможности

- **Личный кабинет администратора** с единым паролем (смена пароля в интерфейсе).
- **Создание опросов**: вопросы трёх типов — одиночный выбор, множественный выбор,
  свободный текст (тип задаётся при создании вопроса).
- **Ручная публикация/снятие** опроса кнопкой.
- **Управление списком классов** (учащийся выбирает класс из выпадающего списка).
- **Обязательная авторизация участника**: имя, фамилия, класс. Без заполнения данных
  к опросу не пускает и выводит сообщение о необходимости внести данные.
- **Прохождение опроса один раз** (см. раздел «Защита от повторов»).
- **Сохранение ответов** в SQLite (имя, фамилия, класс, опрос, ответы, IP, дата).
- **Отчёты**: сводка по каждому вопросу (количество и проценты), индивидуальные
  ответы, выгрузка в **Excel (.xlsx)** и **PDF** (с поддержкой кириллицы).
- **Адаптивная вёрстка** для смартфонов.

## Требования

- Node.js **22.5+** (используется встроенный модуль `node:sqlite`). Рекомендуется
  Node.js 22 LTS или новее. Проверено на Node.js 26.

## Быстрый запуск (локально)

```bash
# Windows / macOS / Linux
node server.js
```

Откройте <http://localhost:3000>.

**Пароль администратора по умолчанию: `admin123`** — обязательно смените его после
первого входа: раздел «Настройки». Пароль хранится в БД в виде хэша (scrypt).

### Первые шаги

1. Войдите в админку (ссылка «Вход для администратора» на главной).
2. В разделе «Классы» добавьте классы (например, `9А`, `10Б`).
3. Создайте опрос, добавьте вопросы и варианты ответов.
4. Нажмите «Опубликовать».
5. Раздайте ученикам ссылку на главную страницу (или прямую ссылку на опрос).

## Настройки (переменные окружения)

| Переменная        | По умолчанию   | Описание |
|-------------------|----------------|----------|
| `PORT`            | `3000`         | Порт сервера |
| `HOST`            | `0.0.0.0`      | Адрес прослушивания |
| `ADMIN_PASSWORD`  | `admin123`     | Пароль администратора при первом запуске |
| `SURVEY_DB`       | `data/app.db`  | Путь к файлу базы данных SQLite |
| `TRUST_PROXY`     | `0`            | `1` — доверять заголовкам `X-Forwarded-For` (за nginx) |
| `ENFORCE_IP`      | `0`            | `1` — дополнительно блокировать повтор с одного IP |
| `FONT_PATH`       | `fonts/DejaVuSans.ttf` | Шрифт для PDF (нужна кириллица) |

## Защита от повторного прохождения

Работают три уровня (требование «один ученик — один раз»):

1. **Уникальность «имя + фамилия + класс»** для каждого опроса — включена всегда.
   Повторная отправка с теми же данными отклоняется (ошибка «Вы уже проходили…»).
2. **Cookie** — после отправки в браузере ставится отметка; с этого устройства
   повторно пройти опрос нельзя.
3. **IP** (опционально, `ENFORCE_IP=1`) — блокирует повторную отправку с одного
   IP-адреса.

> **Важно про IP.** В школе ученики часто выходят в интернет через один общий
> NAT-адрес. Поэтому блокировка по IP по умолчанию **выключена** — иначе после первого
> ученика весь класс не смог бы ответить. Включайте `ENFORCE_IP=1`, только если уверены,
> что каждый участник имеет отдельный IP.

## Развёртывание на VPS (интернет)

Пример для Ubuntu + Node.js 22.

1. **Установите Node.js 22+** (например, через nvm или NodeSource):

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

2. **Загрузите проект** на сервер, например в `/opt/school-survey`:

   ```bash
   sudo mkdir -p /opt/school-survey
   sudo rsync -a --exclude data/app.db . /opt/school-survey/
   ```

3. **Создайте systemd-сервис** `/etc/systemd/system/school-survey.service`:

   ```ini
   [Unit]
   Description=School Survey
   After=network.target

   [Service]
   WorkingDirectory=/opt/school-survey
   Environment=PORT=3000
   Environment=TRUST_PROXY=1
   Environment=ADMIN_PASSWORD=смените_на_свой
   ExecStart=/usr/bin/node server.js
   Restart=always
   RestartSec=3
   User=www-data

   [Install]
   WantedBy=multi-user.target
   ```

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now school-survey
   ```

4. **Настройте nginx** (обратный прокси + HTTPS). Файл
   `/etc/nginx/sites-available/school-survey`:

   ```nginx
   server {
       listen 80;
       server_name опросы.ваша-школа.рф;

       client_max_body_size 5m;

       location / {
           proxy_pass http://127.0.0.1:3000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```

   ```bash
   sudo ln -s /etc/nginx/sites-available/school-survey /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```

5. **Настройте HTTPS** (рекомендуется):

   ```bash
   sudo apt-get install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d опросы.ваша-школа.рф
   ```

После этого приложение доступно по адресу в интернете. Смените пароль администратора
через раздел «Настройки».

## Резервное копирование

Все данные хранятся в одном файле — `data/app.db`. Для резервной копии достаточно
скопировать этот файл (лучше при остановленном сервисе или использовать
`sqlite3 data/app.db ".backup backup.db"`).

## Структура проекта

```
server.js              — HTTP-сервер и все маршруты (API)
lib/db.js              — слой БД SQLite (схема и запросы)
lib/auth.js            — scrypt-хэши паролей и HMAC-сессии
lib/xlsx.js            — генератор .xlsx (без зависимостей)
lib/pdf.js             — генератор .pdf с кириллицей (встраивает шрифт)
public/                — фронтенд (SPA): index.html, css, js
fonts/DejaVuSans.ttf   — шрифт для PDF (лицензия OFL)
data/app.db            — база данных (создаётся при первом запуске)
scripts/               — вспомогательные скрипты и тесты
```
